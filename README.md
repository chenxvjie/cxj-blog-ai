# CXJ Blog AI

为 CXJ Blog 提供基于博客知识库的智能问答服务。

## 技术方案

- Python、FastAPI、LangGraph
- DeepSeek：回答生成与追问解析
- 硅基流动 `BAAI/bge-m3`：文本嵌入，1024 维
- PostgreSQL + pgvector：向量存储与混合检索
- Docker、GitHub、阿里云云效：构建与部署

## 功能目标

- 基于已发布文章检索并回答，提供原文引用
- 支持流式回答与连续追问
- 文章发布、修改或下架后自动更新索引
- 首次上线为已有公开文章补齐嵌入
- 通过博客后端统一身份与每日额度：游客 10 次、登录用户 20 次、管理员不限次
